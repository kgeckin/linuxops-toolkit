INTERPRETATION

How rates are calculated

Transfer rate is the positive difference between consecutive cumulative byte counters, divided by elapsed sample time. If a counter resets, the displayed rate becomes zero. This page intentionally avoids collecting interface addresses or remote connections.

PRIVACY BY DESIGN

Collection boundaries

The collector reads overall CPU, RAM, disk and network counters. It does not read personal files, usernames, running processes, IP addresses, terminal history, passwords or SSH credentials. The dashboard must stay on loopback because it currently has no user authentication. Docker demonstrations show container-scoped measurements and are not proof of host hardware monitoring.
